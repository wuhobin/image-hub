# Image Hub 前端

React + Vite + TypeScript；客户端渲染，无 SSR。独立于根目录的 Spring Boot 项目。

## 运行

需要 Node.js 22.12+。

```powershell
cd frontend
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。

```powershell
npm test
npm run build
npm run preview
```

构建产物在 `dist/`。生产使用静态服务器，配置 SPA 回退至 `index.html`，使 /history、/login、/register 刷新后可访问。开发服务器仅监听本机。

## 演示范围

- 首页：选择、拖拽、预览图片；JPG / PNG / WebP / GIF，单图 10 MB，最多 9 张；模拟进度和上传结果。
- 未登录可选图，跳转登录后保留；登录后返回首页，手动上传。
- 登录：任意 3–32 位用户名与至少 6 位密码即可演示，不验证真实账号。
- 注册：用户名、邮箱、验证码、密码及确认密码；点击获取验证码后使用 123456，不发送邮件。
- 上传记录：内置 Unsplash 示例图片；预览、文件名搜索、格式筛选、复制原始 URL、删除确认。
- 删除会移除当前会话中的图片记录并释放对应的本地预览；提示外链失效。没有真实存储服务可删除。
- 所有状态只保留在内存中，刷新重置。退出登录清空个人记录，新会话重新加载示例数据。
- `cdn.imagehub.example` 是保留的演示域名，复制的 URL 无公网图片；预览使用示例图或本地 Blob URL。
- 没有套餐、计费、API 管理后台或持久化系统。

## 动效

`gsap` + `@gsap/react` 负责首页动效编排：提示文字、标题、说明、上传框与底部步骤依次入场；上传框保持原位淡入，避免透镜错位。星空推进、透镜汇聚、悬停外扩和上传图标抬升由 GSAP 时间线控制，星空相关时间线与 WebGL 共用渲染时钟。移出时按较慢速度反向播放，快速进出不叠加动画。

React 中通过 `useGSAP` 限定作用范围并在卸载时清理动画；`gsap.matchMedia` 在减少动态效果时还原首页内容。入场过程中点击暂停会直接显示完整界面，恢复时不会重新隐藏上传控件。

`src/components/Starfield.tsx` 使用 Three.js：三维星点、约 4.4 秒开场推进、缓慢视角变化和鼠标视差。星点包含明亮内核、柔和光晕和少量近景闪光，使用半浮点纹理与色调映射保留高光层次；圆角矩形透镜让星点连续弯曲、拉长，在窄边缘上汇聚成蓝白星光环。

`Home.tsx` 和 `styles.css` 另用 CSS 锥形渐变、SVG 噪声位移与遮罩实现沿边框游走的细碎高光。该层与星空一起响应暂停和减少动态效果设置。圆角随上传框实际 CSS 尺寸更新，聚焦或拖入图片时增强透镜。参考 [Krea /app](https://www.krea.ai/app) 的三层处理，不保证像素级还原。

鼠标在星空区域内移动时，相机平移并轻微偏转，形成近景移动多、远景移动少的视差；移出区域或窗口失焦后缓动回中，上传框保持固定。缓动按实际帧间隔计算，触摸操作不触发视差。

鼠标进入上传框时，周围星光的透镜范围平滑外扩；离开时更缓慢地内缩恢复。此反馈独立于键盘焦点和上传状态，快速进出会从当前进度反向过渡，暂停时冻结，系统减少动态效果时关闭。

画布按设备限制分辨率，离屏和页面隐藏时暂停；尊重系统减少动态效果设置，并提供手动暂停按钮。WebGL 不可用时保留 CSS 静态背景和完整上传功能。

动效回归检查：启动开发服务器后，在已安装 `agent-browser` 的环境中执行 `powershell -File scripts/check-starfield.ps1`，检查真实 GPU 相机矩阵是否响应鼠标、移出回中、上传框位置稳定、暂停后移动鼠标时画面一致，以及 Shader 错误和手机布局，并将截图保存至 `.qa/`。

后续在当前交互入口接入 Spring Boot 的登录、验证码、上传、记录和删除接口即可。Mock 的客户端校验不能替代后端的鉴权和文件内容校验。
