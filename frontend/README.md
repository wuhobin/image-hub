# Image Hub 前端

React + Vite + TypeScript；客户端渲染，无 SSR。开发时由 Vite 提供热更新，发布时独立构建为静态文件，由 Nginx 托管。

## 运行

需要 Node.js 22.12+。

```powershell
cd frontend
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。

```powershell
npm test
npm run build
npm run preview
```

`npm run build` 输出到 `dist/`，独立部署到 Nginx。`npm run preview` 仅用于本地检查构建产物，不能替代生产服务器；接口联调使用 `npm run dev` 的代理或生产 Nginx。

根目录 `mvn clean verify` 只构建后端，不安装或构建前端。首次前端构建先运行 `npm ci`，更新锁文件后重新安装依赖（Windows 上先停止 Vite）。开发服务器仅监听本机；部署后由 Nginx 支持 `/`、`/history`、`/login`、`/register`、`/profile` 直接访问和刷新。

## 功能范围

- 首页：选择、拖拽和本地预览图片；JPG / PNG / WebP / GIF，单张 10 MB，每批最多 9 张。
- 未登录可选图，登录后保留待上传图片；逐张发送真实请求，显示进度、结果及单张失败原因。
- 注册：用户名、邮箱验证码、密码及确认密码；成功后进入登录页，不自动登录。用户名和邮箱分别唯一。
- 登录：用户名和密码，登录态保存到当前浏览器，刷新后通过后端校验；不同设备的 Token 独立，3 天有效，退出仅注销当前 Token。
- 上传记录：服务端分页、名称搜索、格式筛选、数量与大小统计；预览、复制原始 URL、删除确认。
- 删除成功后同时移除七牛云文件和记录；失败时保留弹窗并显示错误。
- 数据保存在后端 MySQL 和七牛云；本地待上传文件仍需重新选择（刷新后浏览器无法恢复文件）。
- 每日上传额度、总容量配额后续再实现。

开发时将 `.env.example` 复制为 `.env.local`，设置 `IMAGE_HUB_API_TARGET` 为后端地址；所有页面调用同源 `/api`，由 Vite 转发。本机后端使用 9000，因此本地配置为 `http://127.0.0.1:9000`。示例默认 8080。配置修改后重启开发服务器。

生产部署使用 [Nginx 配置](../deploy/nginx/imghub.conf)，静态文件与 `/api` 共用域名，API 反向代理到 Spring Boot，无需跨域配置。只更新前端时无需重启后端，发布和回滚步骤见 [部署教程](../docs/deploy-docker-compose.md)。服务配置和接口见 [后端接入说明](../docs/backend-api.md)。

## 动效

`gsap` + `@gsap/react` 负责首页动效编排：提示文字、标题、说明、上传框与底部步骤依次入场；上传框保持原位淡入，避免透镜错位。星空推进、透镜汇聚、悬停外扩和上传图标抬升由 GSAP 时间线控制，星空相关时间线与 WebGL 共用渲染时钟。鼠标跟随、外扩和回收使用可复用的 GSAP quickTo 缓动，从当前位置衔接，快速进出不叠加动画。

React 中通过 `useGSAP` 限定作用范围并在卸载时清理动画；`gsap.matchMedia` 在减少动态效果时还原首页内容。入场过程中点击暂停会直接显示完整界面，恢复时不会重新隐藏上传控件。

`src/components/Starfield.tsx` 使用 Three.js：三维星点、约 4.4 秒开场推进、缓慢视角变化和鼠标视差。星点包含明亮内核、柔和光晕和少量近景闪光，使用半浮点纹理与色调映射保留高光层次；圆角矩形透镜让星点连续弯曲、拉长，在窄边缘上汇聚成蓝白星光环。

`Home.tsx` 和 `styles.css` 另用 CSS 锥形渐变、SVG 噪声位移与遮罩实现沿边框游走的细碎高光。该层与星空一起响应暂停和减少动态效果设置。圆角随上传框实际 CSS 尺寸更新，聚焦或拖入图片时增强透镜。参考 [Krea /app](https://www.krea.ai/app) 的三层处理，不保证像素级还原。

鼠标在星空区域内移动时，相机平移并轻微偏转，形成近景移动多、远景移动少的视差；移出区域或窗口失焦后缓动回中，上传框保持固定。缓动按实际帧间隔计算，触摸操作不触发视差。

鼠标进入上传框时，周围星光的透镜范围平滑外扩；离开时更缓慢地内缩恢复。此反馈独立于键盘焦点和上传状态，快速进出会从当前进度反向过渡，暂停时冻结，系统减少动态效果时关闭。

画布按设备限制分辨率，离屏和页面隐藏时暂停；尊重系统减少动态效果设置，并提供手动暂停按钮。WebGL 不可用时保留 CSS 静态背景和完整上传功能。

动效回归检查：启动开发服务器后，在已安装 `agent-browser` 的环境中执行 `powershell -File scripts/check-starfield.ps1`，检查真实 GPU 相机矩阵是否响应鼠标、移出回中、上传框位置稳定、暂停后移动鼠标时画面一致，以及 Shader 错误和手机布局，并将截图保存至 `.qa/`。

前端已接入真实接口；后端独立执行鉴权、图片归属检查、大小与文件内容校验。
