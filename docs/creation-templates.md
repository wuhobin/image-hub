# 场景模板与提示词示例库

## 使用

- 首页输入框旁的“从场景模板开始”和顶部“模板库”进入 `/templates`。
- 分类单选、标签单选和关键词可组合筛选；关键词匹配名称、用途说明及标签。
- 模板可有示例图，也可仅展示提示词示例。选择后填写内容，完整提示词默认收起，可展开修改。
- 手动修改提示词后，再改填写项会保留手工内容并提示；“按填写项重新组合”需要确认覆盖。
- “带入创作区”只填提示词，不提交任务或扣积分。模型、比例、分辨率、质量保留当前账号在本标签页的选择；不可用的参数沿用现有模型默认值校验。
- 游客可先浏览和填写，在创作页点击生成后登录。登录、注册切换保留所选模板、填写文字和手动编辑结果；注册仍不自动登录。
- 参考图仍在创作区选填，电商模板也可以不上传。示例图不自动作为生成参考图。

## 后台维护

入口为 `/admin/templates`，使用独立管理员身份。

每个模板包含名称、用途说明、一个分类、最多 10 个标签、提示词、最多 8 个填写项、可选示例图、排序和上架状态。建议只保留 2–4 个填写项。

填写项包含标识、显示名称、示例值、是否必填。标识使用小写字母开头的字母、数字或下划线，例如 `subject`；在正文中使用
`{{subject}}`。有填写项时，正文占位符必须与填写项一一对应；无填写项时将正文作为普通示例原文使用。替换仅处理一轮字面字符串，不执行表达式。最终提交仍受现有
4000 字符限制。

分类和标签均支持新增、改名和排序。标签跨分类复用，同类名称唯一；已删除名称仍占用。引用中的词条不可删除，需先调整所有模板（包括草稿）的关联。

支持两种创建方式：

1. 手动填写内容，保存后可上传独立示例图。
2. 从已公开且公开提示词的成功作品中选择，复制图片和提示词为草稿，再配置填写项并上架。

导入时服务端再次验证可见性，客户端不能传任意图片 URL。示例图使用新的存储对象并保留来源作者与分享编号；导入后原作品撤销分享、隐藏提示词、删除或下架，不影响管理员维护的独立副本。

上传、复制示例图不创建用户图库记录，也不消耗用户积分。图片最大 10
MB，复用真实文件内容校验。图片元数据保存于专用表，不在公开响应中暴露存储定位。替换、移除后的旧云文件清理失败时保留定位，下次替换或移除时重试；不会误删当前图片。正文已保存但图片更新失败时，后台明确提示并保留模板编号供重试。

## 升级

已有数据库先备份，执行 `deploy/db/migrations/20260924_creation_templates.sql`，然后部署后端和前端。新数据库使用最新
`deploy/db/schema.sql`，应用不会自动执行迁移。

新增四张表：`hub_template_term`、`hub_creation_template`、`hub_template_tag`、`hub_template_example`
。均使用数据库维护的秒精度时间及逻辑删除。脚本不会覆盖已存在模板正文或已保存的词条关联。

预置个人、内容、电商三个分类，以及头像、壁纸、祝福图、小红书封面、公众号配图、视频封面、商品主图、商品场景图、促销海报共九个已上架文字模板。可以直接填写使用，也可后台补充示例图。

同步部署 `deploy/nginx/imghub.conf` 的模板库、模板后台路由，以及后端匿名只读接口白名单。前台公开响应不缓存，上下架在下次读取时生效；已经带入创作区的文字仍可作为用户自己的提示词使用。

## 接口

| 方法与路径                                           | 用途                                           |
|-------------------------------------------------|----------------------------------------------|
| GET `/api/app/public/templates`                 | 上架模板分页；page、pageSize、categoryId、tagId、search |
| GET `/api/app/public/templates/terms`           | 分类与标签                                        |
| GET `/api/app/public/templates/{id}`            | 公开详情                                         |
| GET / POST `/api/admin/templates`               | 管理分页 / 创建                                    |
| GET / PUT `/api/admin/templates/{id}`           | 详情 / 更新（含上下架、排序）                             |
| POST `/api/admin/templates/import`              | 按 shareId、title、categoryId 独立导入              |
| POST / DELETE `/api/admin/templates/{id}/image` | multipart file 上传 / 移除                       |
| GET / POST `/api/admin/templates/terms`         | 词表 / 新增                                      |
| PUT / DELETE `/api/admin/templates/terms/{id}`  | 修改 / 逻辑删除                                    |

分页复用平台 `Page<T>`，每页最多 50 条；响应沿用 `Result<T>`。

## 验证

- `mvn clean verify`：实际 HTTP 与 H2 验证匿名读取、管理员隔离、草稿隐藏、筛选、占位符校验、词条引用保护、图片替换失败重试、独立导入和积分不变。
- `npm --prefix frontend test`、`npm --prefix frontend run build`。
- `powershell -ExecutionPolicy Bypass -File frontend/scripts/check-templates.ps1`：独立 agent-browser
  会话和虚构接口验证筛选、手工编辑保护、登录及注册切换、参数保持、后台维护和移动端布局。浏览器检查不会请求真实模型或云存储。
