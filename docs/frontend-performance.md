# 首页性能检查与优化（2026-09-13）

## 结论

首页有明确的加载与持续渲染开销，已在现有工作区版本上完成优化，保留星空、透镜、上传交互和暂停按钮。基线来自本次修改前的工作区构建，包含原有未提交修改，不是 Git HEAD。

确定性收益：首屏静态依赖 JS 总量由约 415.59 KB 降至 311.49 KB，减少约 25%；gzip 由约 134.49 KB 降至 96.88 KB，减少约 28%。新数值包含入口和共享 React runtime，不仅是入口文件。未新增运行时依赖。

## 发现与处理

| 问题 | 已实施的处理 |
| --- | --- |
| HTML 加载 Google 字体样式，CSS 又通过 @import 请求中文字体样式；第三方延迟会影响首屏 | 使用本机系统字体，移除两条外部字体样式链。字体外观会随操作系统略有差异 |
| 首页入口包含登录、注册、历史页 | 保留首页同步入口，其他页面通过 React lazy/Suspense 按需加载 |
| GSAP 同时被首页入场、上传进度和全站提示引用 | 首屏内容保持可见；入场改为轻量 CSS 位移；提示使用浏览器原生动画；进度组件按需加载，保留原进度补间 |
| 星空虽然是动态导入，但首页挂载立即发起加载 | 跨过首屏绘制后在空闲时加载；区域不可见、页面在后台、减少动态效果、省流量模式不启动加载；失败保留 CSS 背景 |
| 上传框旋转渐变每帧重新生成图像，再经过 SVG 噪声滤镜 | 保留静态渐变和透明度闪烁，取消渐变角度逐帧变化；星空透镜动画保持 |
| WebGL 缓冲区随首页批量列表增长，高 DPR 进一步放大像素数 | 背景限制在首屏附近；总绘制像素约 100 万以内；手机 DPR 上限 1；持续慢帧时逐步降低分辨率 |
| 背景跟随屏幕高刷新率持续绘制 | 桌面背景目标上限 60 帧、手机 30 帧；不限制业务 UI 帧率 |
| 暂停、离屏时仍保留每帧回调 | 移除空转 ticker；恢复可见或继续播放时重新调度。尺寸变化仍能刷新静态画面 |
| 选图列表一次性显示所有原始预览 | 缩略图声明尺寸、使用异步解码和浏览器懒加载 |

字体样式阻塞与关键内容显示延迟的判断参考 [web.dev 的 LCP 优化说明](https://web.dev/articles/optimize-lcp)；像素预算参考 [Three.js 的响应式渲染说明](https://threejs.org/manual/en/responsive.html)。

## 浏览器实验

使用本机 Chromium、Vite 生产预览、冷缓存、4 倍 CPU 降速、150 ms 网络延迟、1.6 Mbps 下载。桌面视口 1440×900 / DPR 1，手机模拟 390×844 / DPR 3。页面运行约 16 秒后另采样 5 秒稳态。

最终版本在完成编译和检查、停止同时运行其他检查后进行了一轮单独采样：

| 指标 | 修改前桌面 | 修改后桌面 | 修改前手机模拟 | 修改后手机模拟 |
| --- | ---: | ---: | ---: | ---: |
| FCP（首个内容显示） | 3.556 s | 1.748 s | 2.936 s | 1.888 s |
| LCP（主要内容显示） | 3.716 s | 1.748 s | 3.188 s | 1.888 s |
| 约前 16 秒长任务数（>50 ms） | 16 | 7 | 26 | 6 |
| 长任务超过 50 ms 的累计部分 | 2855 ms | 1105 ms | 2905 ms | 1109 ms |
| 后续约 5 秒 WebGL draw 调用 | 914 | 520 | 976 | 282 |
| 绘制缓冲区像素 | 1425×689 | 1425×686 | 487×758 | 390×607 |

这里的长任务累计值使用自定义观察窗口，**不是 Lighthouse TBT**；draw 调用包含星点和后处理两次绘制，**不是实际屏幕 FPS**。单次采样不代表统计显著改善，更不能作为线上 SLA。

重复测量存在明显波动：一次中间版本复测手机 LCP 达到 5.684 s，桌面稳态帧间隔 P95 达到 215 ms；未将这些结果删去。运行环境和并行系统负载可能影响结果，本次没有隔离所有外部因素。最终单独采样的两个视口均未出现 >50 ms 的稳态帧间隔，但这不能证明所有设备都不卡顿。最终桌面累计布局偏移约 0.00018，手机为 0。

本次没有测量真实用户 INP、真实移动设备 GPU、线上服务器/CDN、登录接口延迟或真实云端上传速度。仍保留约 538 KB 的异步 Three.js 星空模块（gzip 约 136 KB），其初始化仍有开销，弱设备应继续关注；减少动态效果和省流量路径可以完全不加载它。
